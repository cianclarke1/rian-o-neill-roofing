# Rian O'Neill Garden Sheds

A responsive business website developed for Rian O'Neill Garden Sheds, helping customers explore garden shed options and request a quote online.

## Live Website

**https://www.rianoneillgardensheds.ie**

## Features

- Responsive design for desktop and mobile devices
- Home, Range, About and Contact pages
- Timber, metal and premium metal shed listings
- Contact form integration using Formspree
- TikTok video embeds
- SEO metadata, sitemap and robots.txt
- Live deployment through Vercel

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite
- Git and GitHub
- Vercel
- Formspree

## My Contribution

I worked on developing and maintaining the website, improving the responsive layout, integrating product images and video embeds, configuring the contact form, resolving deployment issues, and implementing technical SEO improvements.

The project gave me practical experience working with a real business website, version control and deployment workflows.

## Deployment

The website is hosted on Vercel and connected to GitHub for version control and deployment updates.
